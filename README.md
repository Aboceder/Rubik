# 魔方方魔 · Cube Workbench

一个跑在浏览器里的三阶魔方工作台：可以直接拖动拧层的 3D 魔方，加一套完整的 F2L（前两层）41 条公式的三维演示。

纯静态站点，没有构建步骤，没有后端。Three.js、Tailwind、daisyUI 全部已 vendor 到仓库里，国内网络下不依赖任何 CDN。

## 功能

**自由转动**

- 拖动魔方表面拧动对应的一层，跟手实时旋转；拖动空白区域转视角，滚轮缩放
- 支持鼠标和触屏，移动端可用
- 键盘操作：`U D L R F B` 拧对应面，按住 `Shift` 反向
- 状态实时判定：显示是否已复原、累计步数
- 打乱 / 还原 / 切换视角

**F2L 公式**

- 41 个标准 F2L 局面，每个局面用真实的三维魔方预览，不是静态图片
- 按「未成对 / 角在槽 / 棱在槽 / 都在槽 / 左前槽」分组，可筛选
- 点进详情页可以播放整条公式、单步前后、自由拖动观察
- 每条公式附带讲解：看什么、目标是什么、分成几个阶段，以及每个阶段为什么要这么转
- 随机一题、F2L 练习模式

## 运行

模块和 importmap 需要 HTTP 环境，直接双击 `index.html` 打不开，起个静态服务器即可：

```bash
python3 -m http.server 8000
# 或者
npx serve .
```

然后访问 <http://localhost:8000>。

## 目录结构

```
index.html                  页面结构、样式、importmap
js/
  app.js                    入口，加载 Three.js 并串联各模块
  notation.js               魔方记号解析（U/D/L/R/F/B、宽层、中层、整体旋转）
  state.js                  魔方状态模型：旋转矩阵、拧层、复原判定、F2L 局面分类
  cube-view.js              Three.js 场景、材质、动画、拖拽交互
  cube-thumbnails.js        列表用的轻量魔方缩略图
  f2l-cases.js              41 条 F2L 公式数据与讲解文案
  f2l-detail.js             公式详情页：播放、单步、三维观察
  main.js                   界面控制、路由、事件绑定
vendor/                     Three.js、Tailwind、daisyUI 的本地副本
assets/                     图标
```

## 实现说明

魔方状态用每个小块的位置和朝向表示，拧动就是一次坐标变换。`notation.js` 把 `R U' R'` 这样的记号解析成 `{轴, 层, 角度}`，`state.js` 据此更新状态，`cube-view.js` 负责把状态映射到三维物体并做插值动画。

界面用 daisyUI 组件配自定义主题色，路由是纯 hash 路由（`#f2l`、`#f2l/12`），所以能直接分享某个公式的链接，也能用浏览器前进后退。
